Kelola E-Library
  1. Buka menu E-Library dari dashboard admin.
  2. Isi judul, kategori, deskripsi, dan pilih link eksternal atau file PDF.
  3. Opsional: upload gambar sampul untuk tampilan kartu.
  4. Klik tambah untuk menyimpan data.
  5. Gunakan tombol hapus pada item yang tidak dipakai.
Ke Halaman E-Library
Kelola Dokumentasi
  1. Buka menu Dokumentasi dari dashboard admin.
  2. Isi judul kegiatan, kategori, dan deskripsi ringkas.
  3. Upload gambar dokumentasi dengan ukuran proporsional.
  4. Tambahkan link video (opsional) jika tersedia.
  5. Klik tambah, lalu cek hasilnya di halaman publik.
Ke Halaman Dokumentasi
Kelola Artikel
  1. Buka menu Artikel dari dashboard admin.
  2. Isi judul, kategori, dan deskripsi konten.
  3. Upload gambar dan file PDF jika diperlukan.
  4. Klik tambah untuk menyimpan item baru.
  5. Hapus item lama yang sudah tidak relevan.
Ke Halaman Artikel
Kelola Pengaturan Situs
  1. Buka menu Settings dari dashboard admin.
  2. Perbarui nama situs, tagline, WhatsApp, alamat, email, dan peta.
  3. Pastikan URL Google Maps embed valid.
  4. Klik simpan, lalu refresh halaman publik untuk verifikasi.
  5. Lakukan perubahan seperlunya agar konsisten dengan identitas situs.
Ke Halaman Settings
Catatan Penting
  • Gunakan gambar dengan ukuran ringan agar website tetap cepat.
  • Pastikan tautan eksternal dan video masih aktif sebelum dipublikasi.
  • Setiap perubahan admin langsung memengaruhi tampilan publik.
