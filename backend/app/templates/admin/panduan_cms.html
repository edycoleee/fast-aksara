Panduan Admin

Dokumentasi Penggunaan CMS Ngrembaka Aksara

Panduan ini menjelaskan cara login, memakai dashboard, mengatur settings aplikasi, dan menggunakan semua fungsi CMS.

Kembali ke Login

1. Cara Login Admin

  1. Buka halaman /admin/login.
  2. Masukkan username dan password admin.
  3. Klik tombol Masuk.
  4. Jika berhasil, Anda akan masuk ke dashboard admin.

2. Fungsi Halaman Dashboard

  • Melihat ringkasan total data E-Library, Dokumentasi, dan Artikel.
  • Akses cepat ke menu pengelolaan konten.
  • Akses ke halaman Pengaturan Situs dan Dokumentasi Admin.

3. Fungsi CMS: E-Library

  • Tambah data konten E-Library (judul, kategori, deskripsi, cover).
  • Pilih sumber konten: link eksternal atau upload file PDF.
  • Edit data yang sudah ada.
  • Hapus data yang tidak dipakai.

4. Fungsi CMS: Dokumentasi

  • Tambah dokumentasi kegiatan beserta gambar.
  • Tambahkan link video (opsional).
  • Edit dan hapus data dokumentasi.

5. Fungsi CMS: Artikel

  • Tambah artikel beserta deskripsi, gambar, dan file PDF (opsional).
  • Edit artikel kapan saja.
  • Hapus artikel yang sudah tidak relevan.

6. Fungsi Settings Aplikasi

  • Ubah identitas situs: nama, tagline, alamat, email, Instagram, YouTube.
  • Atur peta Google Maps embed.
  • Atur logo institusi via URL atau upload file langsung.
  • Jika upload logo, sistem otomatis resize ke 96x96 px saat disimpan.
  • Atur SMTP email (host, port, user, password, TLS, dan email tujuan form kontak).
  • Atur teks pembaruan terakhir di footer.

7. Alur Pakai Harian yang Disarankan

  1. Login admin.
  2. Cek dashboard untuk melihat ringkasan data.
  3. Kelola konten (E-Library/Dokumentasi/Artikel) sesuai kebutuhan.
  4. Perbarui Settings jika ada perubahan identitas, logo, peta, atau SMTP.
  5. Setelah simpan, cek hasil di halaman publik.
