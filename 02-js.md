## 2. Tahap 1: Dasar JavaScript (fondasi)

Ini tahap paling penting. Tanpa ini, semua konsep berikutnya akan terasa sulit.

### Yang harus dipelajari:
- variabel: `let`, `const`
- tipe data: string, number, boolean, null, undefined
- operator: aritmatika, perbandingan, logika
- kondisi: `if`, `else if`, `else`
- perulangan: `for`, `while`
- fungsi dasar

### Contoh:
```js
let nama = "Aksara";
const usia = 16;

if (usia >= 17) {
  console.log("Dewasa");
} else {
  console.log("Masih siswa");
}

for (let i = 1; i <= 3; i++) {
  console.log("Iterasi ke-" + i);
}
```

### Target pemahaman:
- ngerti cara kerja program dari atas ke bawah
- bisa menulis logika sederhana
- bisa membaca error di console

### Latihan kecil:
- buat program menghitung jumlah bilangan
- buat program menentukan nilai siswa (A/B/C)
- buat program menampilkan nama dengan urutan tertentu

## 3. Tahap 2: Fungsi dan scope

Fungsi adalah blok kode yang bisa dipakai berulang.

### Yang harus dipelajari:
- function declaration
- function expression
- parameter dan return value
- arrow function
- scope lokal vs global
- hoisting pemahaman dasar

### Contoh:
```js
function hitungLuas(panjang, lebar) {
  return panjang * lebar;
}

const hasil = hitungLuas(5, 4);
console.log(hasil);

const tambah = (a, b) => a + b;
console.log(tambah(3, 7));
```

### Kenapa penting?
Pada aplikasi nyata, kita tidak menulis segala sesuatu satu baris. Kita buat fungsi untuk:
- validasi form
- hitung total
- buka/tutup modal
- filter data
- kirim request ke API

### Latihan kecil:
- fungsi untuk menghitung rata-rata nilai
- fungsi untuk mengecek apakah angka genap
- fungsi untuk menampilkan judul artikel

# 🟦 LATIHAN 5 — Jinja2 + Array of Object (Level Mahir)

## 📁 Backend FastAPI — `main.py`
```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()
templates = Jinja2Templates(directory="templates")

@app.get("/artikel")
def artikel(request: Request):
    data = [
        {"judul": "Aksara Jawa", "kategori": "Budaya"},
        {"judul": "Sejarah Desa", "kategori": "Sejarah"},
        {"judul": "Kebudayaan", "kategori": "Budaya"}
    ]
    return templates.TemplateResponse(
        "artikel.html",
        {"request": request, "judul": "Daftar Artikel", "artikel": data}
    )
```

## 📁 Template Jinja2 — `artikel.html`
```html
{% extends "base.html" %}

{% block content %}
<h2>{{ judul }}</h2>

<h3>Semua Judul</h3>
<ul>
    {% for item in artikel %}
        <li>{{ item.judul }} ({{ item.kategori }})</li>
    {% endfor %}
</ul>

<h3>Filter Budaya</h3>
<ul>
    {% for item in artikel if item.kategori == "Budaya" %}
        <li>{{ item.judul }}</li>
    {% endfor %}
</ul>

<h3>Ubah Format (map)</h3>
<ul>
    {% for item in artikel %}
        <li>{{ loop.index }} - {{ item.judul|upper }}</li>
    {% endfor %}
</ul>
{% endblock %}
```

### 📝 Penjelasan  
- Loop array dengan `{% for %}`  
- Filter langsung di template  
- Format ulang data (mirip `map`)  
- `loop.index` = nomor urut

## 5. Tahap 4: DOM (Document Object Model)

DOM adalah cara JavaScript berhubungan dengan HTML.

### Yang harus dipelajari:
- `document.getElementById()`
- `document.querySelector()`
- `document.querySelectorAll()`
- mengubah teks: `textContent`
- mengubah HTML: `innerHTML`
- menambah elemen baru: `createElement()`
- menghapus elemen

### Contoh:
```js
const judul = document.querySelector("h1");
judul.textContent = "Selamat Datang";

const tombol = document.getElementById("tombol");
tombol.addEventListener("click", () => {
  alert("Tombol diklik");
});
```

### Kenapa penting?
Ini inti untuk membuat website interaktif. Tanpa DOM, JS tidak bisa:
- mengubah teks
- menutup modal
- menampilkan alert
- menambahkan card baru
- menghapus data dari halaman

### Latihan kecil:
- ubah teks judul saat tombol diklik
- sembunyikan menu saat klik
- tambahkan item baru ke list

## 9. Tahap 8: Async JavaScript dan fetch

Ini penting kalau aplikasi harus mengambil data dari backend.

### Yang harus dipelajari:
- callback
- Promise
- async/await
- `fetch()`
- menangani error
- JSON parsing

### Contoh:
```js
async function ambilData() {
  try {
    const response = await fetch("/api/artikel");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Gagal memuat data:", error);
  }
}
```

### Untuk aplikasi ini:
- ambil data artikel dari backend
- tampilkan daftar artikel ke halaman
- tambah data secara dinamis
- edit data tanpa reload

### Latihan kecil:
- ambil data dari API dummy
- tampilkan hasil ke list HTML
- masukkan error handling saat request gagal

## 19. Integrasi JavaScript dengan FastAPI + Jinja2

Pada proyek seperti ini, JavaScript tidak berdiri sendiri. Ia bekerja bersama backend FastAPI dan template Jinja2.

### 1) Peran masing-masing komponen

- HTML: struktur halaman
- CSS: tampilan visual
- JavaScript: interaksi dan logika di browser
- Jinja2: render data dari backend ke HTML
- FastAPI: mengirim data dan menerima request

Jadi alurnya seperti ini:

```text
FastAPI -> ambil data dari database
FastAPI -> kirim ke template Jinja2
Jinja2 -> render HTML
Browser -> membaca HTML
JavaScript -> menambah interaksi di halaman
```

### 2) Contoh integrasi sederhana

Pada backend, route bisa mengirim data ke template:

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()
templates = Jinja2Templates(directory="templates")

@app.get("/")
def index(request: Request):
    data = [
        {"judul": "Aksara Jawa", "kategori": "Budaya"},
        {"judul": "Sejarah Desa", "kategori": "Sejarah"},
    ]
    return templates.TemplateResponse("index.html", {"request": request, "artikel": data})
```

Pada template HTML, data ditampilkan oleh Jinja2:

```html
<div id="artikel-list">
  {% for item in artikel %}
    <article class="card" data-judul="{{ item.judul }}">
      <h3>{{ item.judul }}</h3>
      <p>{{ item.kategori }}</p>
    </article>
  {% endfor %}
</div>
```

Lalu JavaScript bisa menangani interaksi:

```html
<script>
  const cards = document.querySelectorAll('.card');

  cards.forEach(card => {
    card.addEventListener('click', () => {
      const judul = card.dataset.judul;
      alert('Anda memilih: ' + judul);
    });
  });
</script>
```

### 3) Mengapa ini penting?
Karena di proyek nyata, halaman tidak selalu statis. Contoh:
- tombol hapus data pakai konfirmasi
- tombol filter kategori dari list artikel
- search form yang menangkap input user
- modal edit data
- menu mobile yang dibuka/tutup
- validasi form sebelum submit

### 4) Integrasi yang paling sering dipakai di aplikasi ini

#### a. Render data dari backend ke HTML
```python
return templates.TemplateResponse("admin/artikel_form.html", {"request": request, "artikel": artikel})
```

#### c. JavaScript baca data dari atribut HTML

```js
const btn = document.querySelector('.btn-delete');
btn.addEventListener('click', () => {
```

### 5) Prinsip pengajaran yang baik

Untuk siswa, konsep ini harus dijelaskan secara bertahap:

1. Jinja2 menyiapkan data di halaman.
2. HTML menampilkan struktur.
3. JavaScript membaca elemen di halaman.
4. JavaScript menangkap event user.
5. JavaScript mengubah tampilan atau mengirim request.
6. FastAPI memberi respons kembali.

### 6) Contoh alur aplikasi nyata

```text
Admin buka halaman /admin/artikel

    -> backend simpan data
    -> halaman diperbarui kembali
```
