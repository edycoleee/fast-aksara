# Roadmap Belajar Fast-Aksara untuk Anak SMA

Dokumen ini disusun agar anak SMA bisa belajar dari nol sampai mampu membuat web seperti Fast-Aksara secara mandiri.
Urutannya dibuat bertahap supaya tidak bingung dan bisa fokus pada satu kemampuan dulu sebelum naik level.

## 1. Gambaran Umum Jalur Belajar

Target akhir dari pembelajaran ini adalah:

1. Paham cara kerja website.
2. Bisa membuat tampilan web sederhana.
3. Bisa menulis logika backend dengan Python.
4. Bisa membuat web dinamis dengan FastAPI.
5. Bisa menyimpan data ke database.
6. Bisa menampilkan halaman dengan Jinja2.
7. Bisa menjalankan web di server atau Docker.

## 2. Tahapan Belajar

### Tahap 1 — Pengenalan Dasar Komputer dan Web

Tujuan tahap ini adalah memahami apa itu web dan bagaimana sebuah situs bekerja.

Yang perlu dipelajari:

- Apa itu browser.
- Apa itu URL.
- Apa itu server.
- Apa itu frontend dan backend.
- Apa itu database.
- Apa itu domain dan hosting.

Latihan sederhana:

1. Buka beberapa website.
2. Lihat alamat URL di browser.
3. Perhatikan perbedaan halaman depan, halaman profil, dan halaman kontak.
4. Coba buka website dari HP dan laptop untuk melihat perbedaan tampilan.

### Tahap 2 — Belajar HTML

Tujuan tahap ini adalah bisa membuat struktur halaman web.

Yang perlu dipelajari:

- Tag dasar HTML.
- Heading, paragraf, gambar, link, list, table.
- Form sederhana.
- Struktur halaman: `header`, `main`, `section`, `footer`.

Latihan:

1. Buat halaman profil diri.
2. Tambahkan foto, nama, hobi, dan kontak.
3. Buat daftar kegiatan harian.
4. Buat tabel sederhana.

### Tahap 3 — Belajar CSS

Tujuan tahap ini adalah membuat halaman web terlihat rapi dan menarik.

Yang perlu dipelajari:

- Warna.
- Font.
- Margin dan padding.
- Flexbox.
- Grid.
- Responsive design.
- Hover effect.

Latihan:

1. Ubah tampilan halaman HTML yang sudah dibuat.
2. Buat card sederhana.
3. Buat navbar dan footer.
4. Coba tampilan mobile.

### Tahap 4 — Belajar JavaScript Dasar

Tujuan tahap ini adalah memahami interaksi sederhana di browser.

Yang perlu dipelajari:

- Variabel.
- Fungsi.
- Event.
- DOM manipulation.
- Validasi form sederhana.

Latihan:

1. Buat tombol yang mengubah teks.
2. Buat form yang bisa mengecek input kosong.
3. Buat daftar item yang bisa ditambah.

### Tahap 5 — Belajar Python Dasar

Tujuan tahap ini adalah siap masuk ke backend.

Yang perlu dipelajari:

- Variabel dan tipe data.
- if/else.
- perulangan.
- list, dict, tuple.
- function.
- file handling.
- module dan import.

Latihan:

1. Buat program hitung sederhana.
2. Buat program daftar nilai.
3. Buat program yang membaca file teks.

### Tahap 6 — Belajar Python Lanjutan yang Dibutuhkan Web

Tujuan tahap ini adalah memahami dasar yang sering dipakai di backend.

Yang perlu dipelajari:

- class dan object.
- virtual environment.
- package management.
- exception handling.
- JSON.
- HTTP dasar.

Latihan:

1. Buat class data sederhana.
2. Simpan dan baca file JSON.
3. Pahami request dan response.

### Tahap 7 — Belajar FastAPI Dasar

Tujuan tahap ini adalah memahami cara membuat API dan halaman web dengan Python.

Yang perlu dipelajari:

- routing.
- path parameter.
- query parameter.
- request dan response.
- template rendering.
- static files.

Latihan:

1. Buat halaman utama dengan FastAPI.
2. Buat halaman beranda.
3. Buat endpoint JSON sederhana.
4. Tampilkan data dari Python ke template.

### Tahap 8 — Belajar Jinja2

Tujuan tahap ini adalah memahami cara membuat halaman web dinamis.

Yang perlu dipelajari:

- `base.html`.
- `block` dan `extends`.
- loop.
- kondisi.
- template partial.

Latihan:

1. Buat satu template dasar.
2. Buat beberapa halaman turunan.
3. Tampilkan data dari daftar Python.

### Tahap 9 — Belajar Database dan SQLAlchemy

Tujuan tahap ini adalah menyimpan data secara permanen.

Yang perlu dipelajari:

- apa itu database.
- tabel, baris, kolom.
- primary key.
- relasi sederhana.
- SQL dasar.
- SQLAlchemy.

Latihan:

1. Buat tabel data artikel.
2. Simpan data ke database.
3. Tampilkan data dari database.
4. Edit dan hapus data.

### Tahap 10 — Belajar CRUD Admin

Tujuan tahap ini adalah membuat panel admin seperti pada Fast-Aksara.

Yang perlu dipelajari:

- login admin.
- session atau cookie.
- form tambah data.
- form edit data.
- hapus data.
- validasi input.

Latihan:

1. Buat login admin sederhana.
2. Buat dashboard.
3. Buat CRUD untuk satu tabel.
4. Lanjutkan ke beberapa tabel.

### Tahap 11 — Upload File Lokal

Tujuan tahap ini adalah bisa menyimpan gambar dan PDF di server.

Yang perlu dipelajari:

- `UploadFile`.
- validasi file.
- ukuran file.
- rename file.
- simpan ke folder upload.
- hapus file lama.

Latihan:

1. Upload gambar.
2. Upload PDF.
3. Tampilkan file di halaman publik.
4. Ganti file lama dengan file baru.

### Tahap 12 — Membuat Proyek Seperti Fast-Aksara

Setelah dasar selesai, mulai bangun proyek nyata.

Fitur yang perlu dibangun:

- landing page.
- beranda.
- profil.
- e-library.
- pojok literasi.
- admin CMS.
- settings situs.
- upload file.

Latihan proyek:

1. Buat struktur folder.
2. Buat database.
3. Buat template dasar.
4. Buat router halaman publik.
5. Buat login admin.
6. Buat CRUD konten.

## 4. Cara Belajar dari Proyek Ini

Supaya lebih cepat paham, anak SMA bisa belajar langsung dari struktur Fast-Aksara.

### Urutan membaca kode

1. Buka `backend/app/main.py`.
2. Lihat router yang dipakai.
3. Buka satu router, misalnya `profil_aksara.py`.
4. Lihat template yang dipanggil.
5. Buka `base.html` untuk memahami layout.
6. Buka `models.py` untuk memahami data.
7. Lihat `database.py` untuk memahami koneksi database.

### Pola belajar yang bagus

- Baca satu file dulu.
- Coba ubah satu teks kecil.
- Jalankan aplikasi.
- Lihat hasilnya di browser.
- Ulangi dengan fitur lain.

## 5. Project Mini untuk Latihan

1. Profil pribadi.
2. Website sekolah.
3. Galeri foto kegiatan.
4. Blog sederhana.
5. Daftar buku bacaan.
6. CMS mini untuk artikel.

Project mini membantu memahami alur kerja sebelum masuk ke sistem yang lebih besar.

## 6. Kebiasaan Belajar yang Disarankan

1. Belajar sedikit tapi rutin.
2. Selalu praktik, jangan hanya menonton tutorial.
3. Simpan catatan setiap selesai belajar.
4. Ulangi bagian yang belum paham.
5. Coba ubah proyek sendiri setelah mengikuti contoh.
6. Jangan lompat ke materi yang terlalu sulit sebelum dasar kuat.

## 7. Sumber Kemampuan yang Harus Dikuasai

Untuk bisa membuat web seperti ini, minimal harus menguasai:

- HTML dan CSS.
- JavaScript dasar.
- Python dasar dan menengah.
- FastAPI.
- Jinja2.
- SQL dan database.
- Git dan GitHub.
- Deploy sederhana.

## 8. Tanda Sudah Naik Level

Anak SMA bisa dianggap sudah berkembang ke level mahir jika sudah bisa:

1. Membuat layout web sendiri.
2. Menulis backend Python tanpa menyalin mentah.
3. Menghubungkan halaman ke database.
4. Membuat login admin.
5. Menambah fitur upload file.
6. Menyebarkan web ke server.

## 9. Target Akhir Pembelajaran

Target akhir bukan sekadar bisa menjalankan aplikasi ini, tetapi juga:

- bisa membuat web serupa dari nol,
- bisa menambah fitur baru,
- bisa memahami struktur project,
- dan bisa belajar proyek baru secara mandiri.

Dengan urutan ini, anak SMA bisa mulai dari dasar lalu naik bertahap sampai mahir membangun website seperti Fast-Aksara.
