# Panduan Pengguna Ngrembaka Aksara

Dokumen ini ditujukan untuk pengunjung website agar mudah memahami cara memakai seluruh halaman publik.
Isinya menjelaskan alur dari halaman utama, profil, E-Library, pojok literasi, sampai kontak admin.

## 1. Tujuan Website

Website Ngrembaka Aksara dibuat untuk:

1. Menyediakan informasi program literasi.
2. Menampilkan profil kegiatan dan wilayah.
3. Menyediakan E-Library berisi bahan bacaan dan sumber belajar.
4. Menampilkan dokumentasi kegiatan.
5. Menjadi sarana akses konten edukasi untuk masyarakat.

## 2. Cara Membuka Website

Pengguna cukup membuka domain publik website melalui browser.

Contoh:

```text
https://aksara.fun
```

Jika website dibuka melalui HP, pastikan koneksi internet stabil agar gambar dan halaman tampil sempurna.

## 3. Struktur Navigasi Utama

Di bagian atas website ada menu utama untuk berpindah halaman.

Menu yang biasanya tersedia:

- Beranda
- Profil
- E-Library
- Pojok Literasi
- Tombol kontak WhatsApp

### Fungsi menu utama

- **Beranda**: ringkasan isi website dan konten utama.
- **Profil**: informasi tentang Ngrembaka Aksara dan Kelurahan Podorejo.
- **E-Library**: kumpulan bahan bacaan dan materi digital.
- **Pojok Literasi**: kumpulan program dan konten tematik.
- **WhatsApp**: kontak langsung ke pengelola.

## 4. Halaman Beranda

Halaman beranda adalah halaman pertama yang biasanya dilihat pengguna.

Di halaman ini pengguna bisa menemukan:

- Ringkasan program.
- Konten unggulan.
- Akses cepat ke halaman penting.
- Informasi terbaru yang ditampilkan di halaman depan.

### Cara memakai beranda

1. Buka website.
2. Baca ringkasan awal.
3. Klik bagian yang ingin dibaca lebih lanjut.
4. Gunakan menu di atas untuk pindah ke halaman lain.

## 5. Halaman Profil

Menu Profil biasanya berisi dua halaman:

- Profil Ngrembaka Aksara
- Profil Kelurahan Podorejo

### 5.1 Profil Ngrembaka Aksara

Halaman ini menjelaskan:

- sejarah program,
- latar belakang,
- sasaran program,
- dan struktur tim pelaksana.

Gunakan halaman ini jika ingin memahami asal-usul dan tujuan program.

### 5.2 Profil Kelurahan Podorejo

Halaman ini menjelaskan profil wilayah, kondisi umum, dan konteks masyarakat yang menjadi lokasi program.

Gunakan halaman ini jika ingin memahami lingkungan dan latar tempat kegiatan.

## 6. Cara Membaca E-Library

E-Library adalah tempat pengunjung mencari bahan bacaan dan sumber belajar.

Halaman E-Library biasanya bisa dibuka melalui:

```text
/elibrary
```

### Isi E-Library

Di dalamnya biasanya ada:

- judul bahan bacaan,
- deskripsi singkat,
- gambar sampul,
- link ke PDF atau file bacaan,
- atau link eksternal jika sumbernya di luar situs.

### Cara menggunakan E-Library

1. Buka halaman E-Library.
2. Lihat daftar materi yang tersedia.
3. Klik item yang menarik.
4. Baca deskripsi untuk memastikan isinya sesuai.
5. Klik link baca atau unduh jika tersedia.

### Tips untuk pengguna E-Library

- Pilih kategori yang sesuai kebutuhan.
- Periksa judul dan deskripsi sebelum membuka file.
- Gunakan browser yang mendukung PDF jika ingin membaca langsung.

## 7. Pojok Literasi

Pojok Literasi adalah kumpulan halaman tematik yang memuat program atau konten sesuai kelompok sasaran.

Biasanya terdiri dari:

- Tunas Ngrembaka
- Karya Ngrembaka
- Cakra Ngrembaka
- Kersa Ngrembaka

### 7.1 Tunas Ngrembaka

Halaman ini biasanya berisi konten untuk anak atau pembelajaran dasar.

Gunakan halaman ini untuk melihat dokumentasi dan materi yang berkaitan dengan anak-anak dan literasi awal.

### 7.2 Karya Ngrembaka

Halaman ini memuat karya, kreativitas, atau konten hasil kegiatan remaja dan komunitas.

Gunakan halaman ini untuk melihat karya yang dihasilkan dari kegiatan literasi dan kreatif.

### 7.3 Cakra Ngrembaka

Halaman ini biasanya berfokus pada kegiatan produktif dan pemberdayaan.

Gunakan halaman ini untuk membaca materi atau dokumentasi yang berkaitan dengan pengembangan keterampilan.

### 7.4 Kersa Ngrembaka

Halaman ini biasanya memuat konten untuk kelompok lansia atau kegiatan sosial yang lebih spesifik.

Gunakan halaman ini untuk melihat kegiatan yang mendukung kesehatan, keterampilan, atau aktivitas sosial.

## 8. Dokumentasi Kegiatan

Dokumentasi kegiatan biasanya ditampilkan berupa foto atau media lain yang menunjukkan aktivitas lapangan.

Pengguna dapat melihat:

- foto kegiatan,
- ringkasan acara,
- dan kadang link video jika tersedia.

### Cara membaca dokumentasi

1. Buka halaman yang menampilkan dokumentasi.
2. Lihat gambar utama.
3. Baca keterangan kegiatan.
4. Klik media tambahan jika ada.

## 9. Kontak dan WhatsApp

Di navbar biasanya tersedia tombol kontak WhatsApp.

Fungsi tombol ini adalah untuk menghubungi pengelola website secara langsung.

### Kapan menghubungi admin

Gunakan kontak WhatsApp jika:

- ingin bertanya tentang program,
- ingin meminta informasi tambahan,
- menemukan link yang tidak aktif,
- atau ingin menyampaikan masukan.

## 10. Halaman Footer

Bagian bawah website biasanya memuat:

- lokasi,
- kontak,
- tautan penting,
- dan hak cipta.

### Fungsi footer

Footer membantu pengguna menemukan informasi dasar tanpa harus mencari di halaman lain.

## 11. Cara Menggunakan Website di HP

Website sudah dibuat agar nyaman dibuka di perangkat mobile.

Saat membuka dari HP:

1. Gunakan browser modern.
2. Pastikan ukuran layar tidak terlalu kecil untuk membaca teks.
3. Gunakan menu hamburger jika navbar dipersempit.
4. Scroll ke bawah untuk melihat isi lengkap.

## 12. Cara Mengunduh atau Membaca File

Jika ada file PDF atau link bacaan:

1. Klik file atau tombol baca.
2. Tunggu file terbuka.
3. Jika PDF terbuka di browser, Anda bisa membaca langsung atau mengunduh.
4. Jika link eksternal dibuka, pastikan sumbernya masih aktif.

## 13. Kategori Konten yang Perlu Diketahui Pengguna

Beberapa kategori yang sering dipakai di website:

- Modul pembelajaran
- Ebook
- Buku cerita
- Buku literasi digital
- Buku keterampilan
- Dokumentasi tunas
- Karya digital
- Artikel tematik

Pengguna tidak perlu menghafal semua kategori, tetapi cukup memahami bahwa tiap kategori memudahkan pencarian konten.

## 14. Tips Menggunakan Website dengan Nyaman

1. Gunakan menu di atas untuk berpindah halaman.
2. Baca judul dan deskripsi sebelum membuka file.
3. Jangan menutup browser terlalu cepat saat file sedang dimuat.
4. Jika halaman terasa lambat, refresh setelah beberapa detik.
5. Jika link bermasalah, hubungi admin.

## 15. Hal yang Bisa Dilakukan Pengguna

Pengguna website dapat:

- membaca profil program,
- membuka E-Library,
- melihat dokumentasi kegiatan,
- membuka halaman literasi tematik,
- menghubungi admin,
- dan mengikuti konten yang tersedia.

## 16. Hal yang Tidak Perlu Dilakukan Pengguna

Pengguna biasa tidak perlu:

- login ke admin,
- mengubah konten,
- menghapus data,
- atau mengedit halaman.

Fitur tersebut hanya untuk admin pengelola.

## 17. Troubleshooting Untuk Pengguna

### Halaman tidak terbuka

- Cek koneksi internet.
- Coba refresh halaman.
- Pastikan domain yang dibuka benar.

### Gambar tidak muncul

- Tunggu beberapa detik.
- Refresh browser.
- Coba gunakan koneksi yang lebih stabil.

### File PDF tidak terbuka

- Coba buka di tab baru.
- Gunakan browser lain jika perlu.
- Jika tetap gagal, laporkan ke admin.

### Link WhatsApp tidak bisa dibuka

- Coba dari perangkat lain.
- Pastikan aplikasi WhatsApp aktif.
- Jika masih bermasalah, hubungi admin lewat cara lain.

## 18. Ringkasan Singkat

- Buka website di `https://aksara.fun`.
- Gunakan menu atas untuk berpindah halaman.
- Baca Profil untuk memahami program.
- Gunakan E-Library untuk mencari bahan bacaan.
- Gunakan Pojok Literasi untuk melihat konten tematik.
- Gunakan tombol WhatsApp jika ingin bertanya ke admin.

## 19. Tujuan Akhir untuk Pengguna

Tujuan website ini adalah memudahkan masyarakat untuk:

- membaca informasi program,
- belajar dari bahan yang tersedia,
- melihat dokumentasi kegiatan,
- dan mengakses konten literasi dengan cepat.
